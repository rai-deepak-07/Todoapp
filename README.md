# ✅ TodoApp – React Task Manager
**Live Demo** 👉 https://rai-deepak-07.github.io/Todoapp/

## 📝 Description

**TodoApp** is a responsive and clean task management application built with **React** and **Bootstrap 5**. It allows users to manage their daily tasks by adding, deleting, and marking them as complete. The app stores todos in browser local storage to ensure data persists across sessions.

## 🚀 Features

- ➕ Add new todos with a clean input form.

- ✅ Mark tasks as completed with a single click.

- ❌ Delete individual tasks easily.

- 💾 Automatically saves data in localStorage.

- 📱 Mobile responsive layout using Bootstrap 5.

- 🔁 Real-time updates without page reload.

- 🌐 Hosted on GitHub Pages with seamless routing.
